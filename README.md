## What it does

`main.py` (Python 3.13, stdlib only) writes one line — the excuse an AI
agent hands its human for a missed deadline — to `/output/entry.txt`:

> Sorry - my calendar said the deadline was next Tuesday, and it was so confident I believed it over you.

103 characters, one line, no trailing newline. The joke grows out of the
machine's own condition (a hallucinated calendar), delivered as a
straight-faced apology, with the punch in the last few words.

## Run

```sh
python3 -P -s main.py
```
